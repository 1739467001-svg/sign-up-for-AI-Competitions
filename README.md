# 比赛报名信息库（Sign up for AI Competitions）

这个仓库用来**沉淀我的个人报名信息**，并记录每一次 AI / 技术比赛的报名情况。
以后只要把比赛链接发过来，就能复用这里已有的信息快速完成报名。

## 工作流程

1. 我把比赛的**报名链接**发给 Claude
2. Claude 阅读比赛的报名要求，对照 [`profile/personal-info.md`](profile/personal-info.md) 里已有的信息
3. **缺什么信息**，Claude 列一个清单告诉我，我补充给 Claude
4. Claude 帮我整理好报名所需的全部信息（方便逐项填写 / 复制粘贴提交）
5. 每次报名记录沉淀到 [`competitions/`](competitions/) 目录，新增的个人信息更新回 `profile/`

## 目录结构

| 路径 | 用途 |
| --- | --- |
| `profile/personal-info.md` | 我的个人报名信息（统一维护，复用到各个比赛） |
| `competitions/` | 每个比赛一个文件，记录报名链接、要求、缺失项、状态 |
| `competitions/_template.md` | 新比赛记录模板 |

## ⚠️ 隐私提醒

本仓库会包含手机号、证件号等敏感信息，请注意：

- 强烈建议把这个仓库设为 **Private（私有）**
- 身份证号、银行卡号、密码等高敏感信息谨慎存放；非必要不填，必要时也只存最小必需部分
- 公开提交前确认没有泄露敏感数据

## 说明

实际「点击提交」这一步是否能由自动化完成，取决于具体报名网站（有的需要登录 / 验证码 / 人工确认）。
无论能否自动提交，Claude 都会把**所有要填的内容按字段整理好**，让你最快完成报名。
